## Overview

A local-first intelligent analysis workbench for complex tables. Transforms messy Excel/CSV/TXT data into quality repair plans, insight cards, and explainable reports.

## Quick Start

```bash
docker compose up --build
```

Open http://localhost:8000 for the analysis API service.
